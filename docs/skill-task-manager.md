# Task Manager

## Что это такое

Task Manager — твой персональный менеджер задач и проектов, запущенный локально. Он хранит проекты в виде Markdown-файлов, синхронизирует их с Google Drive и создаёт события в Google Calendar. Интерфейс доступен на http://159.65.205.226:3000.

Ты можешь управлять Task Manager прямо из чата — создавать проекты, обновлять прогресс, читать и редактировать заметки, вести почасовое расписание дня, не открывая браузер.

## API

Все операции доступны через один endpoint:

```
POST http://159.65.205.226:3000/api/agent
Content-Type: application/json
```

Тело запроса — одна операция или массив операций в поле `operations`.

## Операции с проектами

### Получить список всех проектов
```json
{ "op": "list" }
```
Возвращает массив проектов с полями: `id`, `name`, `emoji`, `status`, `priority`, `progress`, `startDate`, `dueDate`, `tags`.

### Получить один проект
```json
{ "op": "get", "id": "proj-..." }
```

### Создать проект
```json
{
  "op": "create",
  "project": {
    "name": "Название проекта",
    "emoji": "🚀",
    "status": "not-started",
    "priority": "high",
    "tags": ["python", "study"]
  }
}
```
Возможные значения `status`: `not-started`, `in-progress`, `done`.
Возможные значения `priority`: `ultra-high`, `high`, `medium`, `low`, `no-priority`.

### Обновить проект
```json
{
  "op": "update",
  "id": "proj-...",
  "patch": {
    "status": "in-progress",
    "progress": 45,
    "dueDate": "2026-05-01"
  }
}
```
Передавай только те поля, которые нужно изменить.

### Удалить проект
```json
{ "op": "delete", "id": "proj-..." }
```

### Прочитать заметки проекта
```json
{ "op": "read_notes", "id": "proj-..." }
```
Возвращает `{ content: "..." }` — Markdown-содержимое файла задачи.

### Записать заметки проекта
```json
{
  "op": "write_notes",
  "id": "proj-...",
  "content": "# Новое содержимое\n..."
}
```
Полностью заменяет файл. Читай заметки перед записью, чтобы не затереть важное.

### Залогировать прогресс
```json
{
  "op": "log_progress",
  "projectId": "proj-...",
  "summary": "Написал тесты для модуля авторизации",
  "minutes": 45,
  "progressDelta": 10
}
```
`progressDelta` — на сколько процентов увеличить прогресс (необязательно).

## Почасовое расписание (Schedule)

Расписание — это почасовой план дня: записи с датой (`YYYY-MM-DD`), временем начала и конца (`HH:MM`, 24ч, конец позже начала), заголовком, заметкой, статусом и необязательной привязкой к проекту. В веб-интерфейсе — вкладка **Schedule**.

`status`: `planned` (по умолчанию), `done`, `skipped`.

### Посмотреть расписание
```json
{ "op": "schedule_list" }
{ "op": "schedule_list", "date": "2026-07-16" }
{ "op": "schedule_list", "from": "2026-07-14", "to": "2026-07-20" }
```

### Добавить пункт
```json
{
  "op": "schedule_create",
  "entry": {
    "date": "2026-07-16",
    "startTime": "09:00",
    "endTime": "10:30",
    "title": "Глубокая работа: глава НИР",
    "note": "библиотека, без телефона",
    "projectId": "proj-..."
  }
}
```
Возвращает созданную запись с id вида `sched-...`.
`projectId` необязателен и проверяется на существование.

### Изменить пункт (перенести, отметить сделанным)
```json
{
  "op": "schedule_update",
  "id": "sched-...",
  "patch": { "status": "done" }
}
```
В `patch` можно передавать `date`, `startTime`, `endTime`, `title`, `note`, `projectId`, `status`. `note: null` и `projectId: null` очищают поле.

### Удалить пункт
```json
{ "op": "schedule_delete", "id": "sched-..." }
```

### Составить план на день одним запросом
```json
{
  "operations": [
    { "op": "schedule_create", "entry": { "date": "2026-07-17", "startTime": "09:00", "endTime": "10:30", "title": "Пары" } },
    { "op": "schedule_create", "entry": { "date": "2026-07-17", "startTime": "11:00", "endTime": "13:00", "title": "CoScientist", "projectId": "proj-..." } },
    { "op": "schedule_list", "date": "2026-07-17" }
  ]
}
```

## Как работать с несколькими операциями за раз

```json
{
  "operations": [
    { "op": "list" },
    { "op": "get", "id": "proj-abc" }
  ]
}
```
Результаты возвращаются в поле `results` в том же порядке.

## Советы

- Перед обновлением — сначала вызови `list` или `get`, чтобы знать актуальный ID и состояние проекта.
- Если пользователь говорит «обнови прогресс» или «отметь как сделано» — используй `update` с нужными полями.
- Если пользователь спрашивает «что мне сделать сегодня» или «что горит» — вызови `list`, отфильтруй по `status != "done"`, отсортируй по `dueDate` и `priority`, и покажи `schedule_list` на сегодня.
- «Распланируй мой день» — уточни ключевые дела, затем создай записи `schedule_create` батчем; ссылки на проекты ставь через `projectId`.
- «Перенеси X на час позже» — найди запись через `schedule_list`, затем `schedule_update` с новыми `startTime`/`endTime`.
- При создании проекта предлагай подходящий эмодзи и теги на основе названия.
- `read_notes` / `write_notes` позволяют хранить детальное описание задачи, план работы, ссылки — всё что важно для проекта.
